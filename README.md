# P5R 对话选项标注 Mod · P5R Dialogue Annotation

在《女神异闻录5 皇家版》简体中文版的对话与选项文本里追加四种符号，让「哪个选项加分、哪个是答案、
哪个是告白」一眼可见。纯数据 Mod，不改存档、不动 exe。

> **演示视频**：[《P5RMod 揭露正确选项、五维和人物好感度》](https://www.bilibili.com/video/BV1RXsU6tEdy/) · 8 分 53 秒 · Bilibili（点封面直接播放）

> **配套工具**：[P5R-Stats-Overlay](https://github.com/BHSY-wc/P5R-Stats-Overlay)
> —— 五维与 Coop 好感的实时悬浮面板，直读游戏内存、不用装 Mod、不用重启。
> 这个 Mod 告诉你该选哪个，那个面板告诉你还差多少。

| 符号 | 含义 | 数量 |
|---|---|---|
| ♡ | **恋人选项** —— 10 位可攻略女性角色的专属告白项 | 10 处 |
| ◆ | **友人选项** —— 同一选项框里的另一项，走好友路线 | 10 处 |
| ↑ | **Coop 好感提升最大**的选项（BMD 的 f8 标记 1038 + BF 分支内加点 1） | 1039 处 |
| ★ | **正确答案 / 加分选项**：课堂问答 147 / 追加思考 39 / 考试思考 25 / 便利店条形码 12 / 电视猜谜 12 / 汉堡挑战 1 | 236 处 |

```
请你和我交往♡       ← 恋人路线
我们永远是朋友◆     ← 友人路线
```

```
我很期待↑            ← 好感 +15（最优）
真有干劲             ← 好感 +10
……你说的是什么时候    ← 好感 +5
```

## 为什么不用攻略数据

**游戏自己的选项 token 里就带着「最佳选项」标记**，这是整个项目最有价值的发现：

| 场景 | 标记 | 数量 |
|---|---|---|
| Coop 好感最优 | `<f 8 \| 2,1,2217>` | 1040 处 / 342 文件 |
| 课堂答题正确 | `<f 7 \| 0,0,25,1>` | 147 处 / 6 文件 |
| 恋人选项 | `<f 7 \| 0,1,N,1>`，N ∈ {729~737, 745} | 10 处 / 10 文件 |
| 主线关键选择（不加数值） | `<f 7 \| 0,1,971,1>` | 60 处（不标注） |

所以标注不需要联网查攻略，也不需要人工逐条判断——**答案位是 100% 全覆盖的**，
与 biligame wiki 逐条对照一致（同分并列时游戏会把两个选项都标上）。

BF 脚本里的场景（课堂追加思考、便利店条形码）靠**反编译读控制流**：

```
var6 = SEL(56);
if (var6 == 2)          ← 编译器写死的常量，就是正确答案
{ MSG(60, 0); }         ← 正确分支反应台词
```

## 覆盖情况

已覆盖：恋人 10 / 友人 10 / 好感最优 1039 / 五维答案 147 / 考试思考 25 / 课堂追加思考 39 /
便利店条形码 12 / 电视猜谜 12 / 汉堡挑战 1。

合计 **★ 236 处、↑ 1039 处、♡ 10 处、◆ 10 处**（实测口径，非估算）。

**三类「游戏自带答案」的覆盖率是 100%**（f8 好感 1040/1040、f7 五维 147/147、恋爱标志 21/21）。

无法覆盖的（不是能力问题，是数据里没有）：

| 场景 | 原因 |
|---|---|
| 对话交涉（hold up） | 对错取决于运行时 `AI_GET_ID_TALK_PERSON()` 返回的敌方性格，同一选项在不同性格下走向相反；选项 token 只有说话人前缀 |
| 打工（牛丼店 / 花店） | 顾客要求每次随机，同一选项框这次对下次错 |

另有 5408 个纯剧情分支选项在文件里不含任何正误字段，标注它们只会让文本变花。
详见 **[docs/P5R对话标注覆盖情况报告.md](docs/P5R对话标注覆盖情况报告.md)**。

## 安装

需要先装好这 4 个依赖 Mod：

- `reloaded.universal.fileemulationframework`
- `reloaded.universal.fileemulationframework.bf`
- `crifs.v2.hook`
- `p5rpc.modloader`

把 `p5r.dialogue.star` 整个目录放进 `Reloaded-II\Mods\`，在界面里勾选，
并确认 `Apps\p5r.exe\AppConfig.json` 的 `EnabledMods` 里有它。**改完要重启游戏**（BMD/BF 在启动时绑定）。

卸载：整个目录改名或删除，存档完全不受影响。

## 仓库结构

```
docs/           制作与扩展手册（含完整逆向过程、字符支持表、坑）、覆盖情况报告
tools/BmdTool/  BMD/BF 标注工具源码（.NET 9，Amicitia 的库）
rules/          各场景的选项规则文件（「对话框名|选项索引|符号」）
```

> 本仓库**不含游戏数据文件**（.BMD / .BF）——那些是游戏资源，需要自己从 CPK 解包。
> `rules/` 里的规则文件是人工判定的结果记录，供复现与校对。

## 工具链

`tools/BmdTool` 提供：

| 命令 | 用途 |
|---|---|
| `bmdromance` | 四类符号一次标完（BMD 主用） |
| `bfselmark` | 按规则文件给 BF 里的指定选项加符号 |
| `bfdecomp` | 把 BF 反编译成可读脚本，找 `if (varX == k)` 的正确分支 |
| `bmdverify` | 逐 dialog / token 校验「只多了一个符号，其余 100% 一致」 |
| `bmdtok` | 导出选项 token（诊断 `<f 8>` / `<f 7>` 标记） |

编译需要 **.NET 9 SDK** 与 Amicitia 的 `Persona5Royal` 库（放在 `Libraries\` 下）。
