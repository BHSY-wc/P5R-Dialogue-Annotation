## 一、核查方法

标注能不能做，取决于**游戏数据里有没有"这是正确答案"这个字段**。本次核查把判据分成三层，逐层比对：

| 层 | 判据                              | 位置        | 可靠度       |
| - | ------------------------------- | --------- | --------- |
| A | `f8` 函数标记（`<f 8 \| 2,1,2217>`）  | BMD 选项文本内 | 编译器写入，零推断 |
| B | `f7` 函数标记（`<f 7 \| 0,0,25,1>`）  | BMD 选项文本内 | 编译器写入，零推断 |
| C | `CMM_ADD_POINT` 系列指令落在 SEL 分支体内 | BF 指令流    | 反编译控制流，可靠 |

`f8` 是合作角色好感加点声明，`f7[0,0,25]` 是五维正确答案声明，`f7[0,1,729~745]` 是恋人路线标志。  
这三类之外，BMD 里的选项就只剩 `<f 5>`（说话人）和 `<f 1>`（换行），**没有任何对错信息**。

## 五、附录：五维面板修复记录

### 5.1 体贴 / 魅力错位（已修复）

**现象**：游戏里明确提示"魅力提升"，面板涨的却是"体贴"。

**根因**：`StatNames` 的数组顺序与内存读取顺序不一致。

内存 / 存档里五项固定为：

```
[0] Knowledge   知识
[1] Charm       魅力
[2] Proficiency 灵巧
[3] Guts        勇气
[4] Kindness    体贴
```

而代码写成了 `{ "知识", "体贴", "灵巧", "勇气", "魅力" }` —— 索引 1 和 4 贴反。

**佐证**：阈值表本身是对的，魅力 Lv2 只要 6 点（五项里最低）、体贴 Lv2 要 14 点；这组数值跟着索引 1 走，而索引 1 被命名为"体贴"，于是"6 点升二级"被错标到体贴头上。名字错、数值对，正好造成互换。

**修复**：`StatNames` / `StatEn` 对调索引 1 与 4，阈值表只改注释。涉及 4 个文件：

- `P5ROverlay/Core/CoopTable.cs`
- `p5r_panel.py`
- `p5r_stats_coop.py`（含表头顺序）
- `p5r_stats_live.py`

### 5.2 面板 UI 改造（P5R 菜单风格）

参照游戏内「饰品 / ACCESSORY」一览，重写了绘制层。

**新增 `UI/P5RStyle.cs`** —— P5R 绘制原语：

| 原语                      | 说明                           |
| ----------------------- | ---------------------------- |
| `Skew` / `Tag`          | 平行四边形 / 左端带尖角的标签块            |
| `Slab`                  | 斜切块（填充 + 细边）                 |
| `Pill`                  | 白色胶囊（右端数值标签）                 |
| `Halftone`              | 半调网点纹理（缓存 tile，不逐点绘制）        |
| `Text`                  | shear 矩阵做右倒文字（不用斜体字库，中文字形更稳） |
| `EaseOut` / `EaseInOut` | 缓动函数                         |

**视觉规则**：

- 底色纯黑 `#070709`，右侧一条出血红斜带，底部极淡网点
- 标题：白色斜切牌 + 黑字（收起态牌面铺满整条）
- 标签页：斜切块，选中项红底白字 + 底部白线
- 五维每行：斜切底板 → 左侧红色竖条 → 名称 → 右端白色胶囊数值 → 红色 Lv 徽章 → 斜切进度条 → 距下一级
- 好感每行：深灰底板 / 可升级墨绿底板 / 满级红底板，三档一眼可分

**动画**（`PageBase` 内建，播完自动停表，不常驻吃 CPU）：

- 数据变化时错峰滑入（每行延迟 35~60ms）
- 进度条按 `EaseOut` 生长
- 数值从 0 滚到实际值

**字体**：`Microsoft YaHei UI` Bold，标题走 shear 倾斜；正文保留 GDI `TextRenderer` 以维持清晰度，标题改 GDI+ 自绘以消除白底上的 ClearType 彩边。

**配色调整**：默认色板改为 P5R 三色（黑 `#070709` / 白 `#F6F6F9` / 红 `#E2002C`）；用户自定义颜色仍可在设置页调整。
