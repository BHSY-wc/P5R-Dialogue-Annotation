# P5R 对话选项标注 Mod · 安装教程

**这是给「只想装上打游戏」的人看的。** 想知道原理、想自己改、想扩展场景，
看同目录的《P5R对话标注Mod-制作与扩展手册.md》。

> Mod ID：`p5r.dialogue.star` ｜ 版本 v0.2.2
> 适用：**Persona 5 Royal 简体中文版（Steam，游戏版本 1.0.4）**

---

## 一、这个 Mod 装完长什么样

游戏里的选项文本后面多一个符号，四类互不重叠：

| 符号 | 含义 | 数量 |
|---|---|---|
| ♡ | **恋人路线**专属告白项 —— 选它进恋人结局 | 10 处 |
| ◆ | **友人路线** —— 同一选项框里的另一项 | 10 处 |
| ↑ | **好感加得最多**的那个选项 | 1039 处 |
| ★ | **正确答案 / 加分选项**（答题、考试思考、便利店条形码、电视猜谜、汉堡挑战） | 236 处 |

效果：

```
我很期待↑              ← 好感 +15，最优
真有干劲               ← 好感 +10
……你说的是什么时候     ← 好感 +5
```

```
请你和我交往♡          ← 恋人
我们永远是朋友◆        ← 友人
```

**不动存档、不动 exe、不改游戏本体**，只通过 Mod 加载器替换 CPK 数据包里的脚本文件。

## 二、前置条件（必须先有这些，缺一个都不显示）

| 前置 | 作用 | 缺了会怎样 |
|---|---|---|
| **Reloaded-II** | Mod 加载器本体 | 无处加载，装了也白装 |
| **p5rpc.modloader** | P5R 专用加载钩子 | 游戏启动时不认 Mod |
| **crifs.v2.hook** | CPK 文件系统钩子 | 替换的 BMD/BF 读不到 |
| **Reloaded.Universal.FileEmulationFramework** | 文件虚拟替换框架（核心） | 同上 |
| **…FileEmulationFramework.BF** | BF 脚本格式支持 | BF 里的 ★ / ↑ 失效 |
| 游戏版本 **1.0.4** | 文件偏移与版本绑定 | 可能闪退或标注错位 |

> BMD 是文本数据，由 FileEmulationFramework 主模块处理；
> BF 是脚本，**必须额外装 `.BF` 那个插件**，否则只有对话文本的符号，答题/思考类的 ★ 全没。

## 三、安装步骤

### 第 1 步：装 Reloaded-II

从官方发布页下载便携版（zip），解压到任意**非中文、非系统盘保护目录**，例如：

```
D:\Reloaded-II\
```

双击 **`Reloaded-II.exe`** 启动。

首次启动如果提示缺 .NET 运行时，按提示装一次（Reloaded-II 自己会给出下载链接）。

> 路径建议全英文。中文路径在部分插件里会出现编码问题，虽然多数情况能用，
> 但排错时会多一个变量 —— 不值得。

### 第 2 步：添加 P5R

1. 点界面左上角 **「Add Application」**（有的版本是 `+` 号）
2. 选到你的游戏 exe：`...\Steam\steamapps\common\P5R\P5R.exe`
3. 添加后左侧应用列表会多出 **P5R**，点中它

### 第 3 步：装五个前置 Mod

在 Reloaded-II 里进 **「Download Mods」**（下载 Mod）页，搜索并安装：

| 搜索关键词 | 装哪个 |
|---|---|
| `p5rpc.modloader` | P5R PC Mod Loader |
| `crifs.v2.hook` | CriFs.V2.Hook（可能显示为 `CriFs.V2.Hook.Awb`） |
| `reloaded.universal.fileemulationframework` | Universal File Emulation Framework |
| `fileemulationframework.bf` | 上面那个的 BF 插件 |
| `fileemulationframework.bmd` | 上面那个的 BMD 插件（建议一并装） |

装完这些会出现在 Reloaded-II 的 Mods 列表里。

**下载页搜不到怎么办**：去 GameBanana 的 P5R 分区手动下 zip，
解压后把整个文件夹丢进 `D:\Reloaded-II\Mods\`，重启 Reloaded-II 就会识别。

### 第 4 步：放本 Mod

把 `P5R正确对话选项标注Mod_冰寒石英.zip` 解压，得到 `p5r.dialogue.star` 文件夹，
**整个文件夹**放进：

```
D:\Reloaded-II\Mods\p5r.dialogue.star\
    ├─ ModConfig.json
    ├─ README.md
    ├─ 文档\
    └─ P5REssentials\CPK\SC.CPK\...
```

放完的正确形态是 `Mods\p5r.dialogue.star\ModConfig.json` 直接存在 ——

> ⚠️ **最常见的错**：解压出的是 `Mods\p5r.dialogue.star\p5r.dialogue.star\ModConfig.json`（多套了一层）。
> 多套一层 Reloaded-II 就认不出来，列表里没有这个 Mod。

重启 Reloaded-II，列表里应出现
**「对话选项标注（♡恋人 ◆友人 ↑好感 ★答案）」**，作者「冰寒石英」。

### 第 5 步：启用并启动游戏

1. 点中列表里这个 Mod，**勾上前面的复选框**
2. 确认这几个也是勾选状态：`p5rpc.modloader`、`crifs.v2.hook`、`FileEmulationFramework`、`.BF`、`.BMD`
3. 点右上 **「Launch Application」** 启动游戏（**必须从 Reloaded-II 启动**，直接点 Steam 的「开始游戏」不会加载 Mod）

> 有些版本需要在 Reloaded-II 里点「**Save**」或「**Pack**」把配置写进
> `Apps\p5r.exe\AppConfig.json` 的 `EnabledMods` 才生效。看到 Save 按钮就点一下。

## 四、验证装成功了没

不用打完序章，开局几分钟就能验证：

| 场景 | 出现时间 | 看什么 |
|---|---|---|
| **课堂提问** | 第一天上课就有 | 正确答案后有 **★** |
| **Coop 对话** | 第一次和角色加深关系 | 最优选项后有 **↑** |
| **恋人告白** | 攻略角色 Rank 9 | 告白项 **♡**、朋友项 **◆** |

**最快的验证**：进游戏第一堂课，老师提问，四个选项里带 ★ 的就是加分答案。

如果一个符号都看不到，按下面顺序查：

| 检查 | 怎么做 |
|---|---|
| 1. 是不是从 Reloaded-II 启动的 | 从 Steam 直接启动 = 不加载 |
| 2. Mod 有没有勾上 | Reloaded-II 列表里复选框状态 |
| 3. 五个前置全不全 | 少 `.BF` 插件 → BF 类标注失效；少 `crifs.v2.hook` → 全部失效 |
| 4. 游戏语言对不对 | **本 Mod 只做简体中文版**（`SC.CPK`）。英文版/日文版路径是 `US.CPK`/`JP.CPK`，不生效 |
| 5. 游戏版本 | 必须 1.0.4，其他版本不保证 |
| 6. 是不是叠了别的文本 Mod | 同时装了别的改同一批 BMD 的 Mod 会互相覆盖，谁后加载谁生效 |

## 五、卸载 / 回滚

**整体卸载**（推荐，最干净）：

```
D:\Reloaded-II\Mods\p5r.dialogue.star\   →  整个文件夹删掉
```

或者在 Reloaded-II 里取消勾选（同时从 `Apps\p5r.exe\AppConfig.json` 的 `EnabledMods` 里移除这一项）。

**只撤某一类场景**（想留 ↑ 但不要答题 ★）：

删对应子目录即可，比如

```
删 ...\SC.CPK\EVENT_DATA\SCRIPT\   → 撤掉考试/课堂思考类的 ★
删 ...\SC.CPK\FIELD\TV\            → 只撤电视猜谜
```

**存档完全不受影响。** 这个 Mod 改的全是 CPK 里的只读数据包，和 16 个存档槽没有任何关系，
装上卸下随便来回，存档不会坏也不会回档。

## 六、和其他 Mod 的关系

| 类型 | 能不能共存 |
|---|---|
| 换装 / 立绘 / UI Mod | ✅ 能，改的不是同一批文件 |
| 别的「对话文本」类 Mod（汉化补丁、文本优化） | ⚠️ 会冲突，改的是同一批 BMD，后加载的覆盖前面的 |
| 存档修改器 / 数值 Mod | ✅ 能，原理完全不搭界 |
| 五维人物好感面板（本项目另一个工具） | ✅ 能，那个是外部悬浮窗，不碰游戏文件 |

## 七、安装常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Reloaded-II 列表里找不到这个 Mod | 多套了一层文件夹 | 确认 `Mods\p5r.dialogue.star\ModConfig.json` 直接存在 |
| 勾上了但启动游戏闪退 | 前置缺失 / 版本不对 | 先只勾本 Mod 的五个前置试；确认 1.0.4 |
| 只有文本里有 ↑，答题类没有 ★ | 缺 `.BF` 文件模拟插件 | 补装 `FileEmulationFramework.BF` |
| 符号变成了方块 / 问号 | 字体不支持 | 用的是官方中文字体，正常不会；若改过字体 Mod，换回原版 |
| 之前能用，更新游戏后失效 | 游戏更新换了文件版本 | 等 Mod 更新，或自行按手册第九章重做 |
| 装完没变化，但列表显示已启用 | 从 Steam 启动的 | 必须从 Reloaded-II 的 Launch Application 启动 |
